# Lucas Viana

Desenvolvedor em formação, focado em criar sites, automações e sistemas simples para pequenos negócios que precisam vender melhor, economizar tempo e organizar processos.

Atualmente estou construindo um portfólio voltado para soluções reais: páginas institucionais, automações de orçamento, dashboards de vendas, controle de estoque e sistemas internos para empresas que ainda dependem de WhatsApp, planilhas soltas e processos manuais.

## O que eu estou construindo

- Sites institucionais para negócios locais
- Landing pages para captação de clientes
- Automações de orçamento e atendimento
- Dashboards de vendas, pedidos e estoque
- Sistemas simples para operação interna

## Projetos em destaque

### Site institucional para pequenos negócios

Página completa com apresentação, serviços, benefícios, depoimentos, FAQ, formulário e botão de WhatsApp.

Objetivo: ajudar negócios locais a passarem mais confiança e receberem contatos qualificados.

### Automação de orçamentos

Ferramenta para calcular serviços, aplicar desconto, definir validade e gerar mensagem pronta para enviar ao cliente.

Objetivo: reduzir trabalho manual e acelerar o atendimento comercial.

### Dashboard de vendas e estoque

Painel para registrar vendas, calcular faturamento, estimar lucro, acompanhar ticket médio e alertar estoque baixo.

Objetivo: transformar dados simples em decisões melhores para pequenos negócios.

## Tecnologias que estou usando

- HTML, CSS, JavaScript, Python, React, Node.js, Supabase, APIs e automações
- Interfaces responsivas
- Git e GitHub
- LocalStorage
- Formulários e lógica de negócio

## Meu foco

Meu objetivo é unir desenvolvimento com visão de negócio. Não quero criar apenas telas bonitas; quero construir soluções que ajudem empresas pequenas a resolver problemas práticos, como:

- vender mais pelo WhatsApp
- responder clientes mais rápido
- organizar pedidos
- controlar estoque
- criar orçamentos com menos erro
- enxergar melhor faturamento e lucro
